# 갤럭시에서 앱 설치하기

## 다운로드

1. 갤럭시 폰에서 EAS Build 링크 열기 (예: `https://expo.dev/artifacts/eas/xxx.apk`)
2. `.apk` 파일 다운로드

## 설치 (출처를 알 수 없는 앱 허용 필요)

1. 다운로드된 `.apk` 파일 탭
2. "이 출처의 앱 설치 허용" 안내가 뜨면 → **설정으로 이동** → 토글 **ON**
3. 뒤로가기 → **설치** 진행
4. 설치 완료 후 앱 실행

> 삼성 One UI 기준: 설정 → 앱 → 오른쪽 상단 점 3개 → 특별한 앱 권한 → 출처를 알 수 없는 앱 설치 → 해당 브라우저(크롬 등) 허용

## 권한 허용

- 첫 실행 시 **마이크 권한 요청** → **허용**
- 인터넷 권한은 자동 적용

## 업데이트

새 빌드 링크가 공유되면 같은 절차로 재설치합니다. 기존 앱 데이터는 유지됩니다.
