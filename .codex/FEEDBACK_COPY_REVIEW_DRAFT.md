## 8. 앱 반영 시 주의사항

- 앱 반영은 대표님/전문가 확인 후 별도 작업으로 진행합니다.
- `EvalResultScreen.tsx`의 result card 문구와 `TrainingScreen.tsx`의 사후 측정 문구는 별도로 존재하므로, 한쪽만 바꾸면 앱 내 문구가 다시 어긋날 수 있습니다.
- `soft_palate`, `tongue_tension`은 현재 앱-side fallback 문구가 있어 server 문구가 비어 있거나 invalid일 때 사용자에게 직접 노출될 수 있습니다.
- `breathiness`는 `낮음/높음` 표현이 평가표 점수 방향과 충돌할 수 있어 대표님 확인 전 수정하지 않습니다.
- 비활성 5항목은 정식 피드백처럼 보이지 않게 `참고용`, `추가 검증 후 정식 피드백 예정` 톤을 유지합니다.
- 점수 방향 확인 없이 graph threshold, score mapper, timeline mapping, server 기준을 바꾸지 않습니다.
