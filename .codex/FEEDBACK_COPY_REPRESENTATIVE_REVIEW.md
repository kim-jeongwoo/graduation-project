# 29 - 대표님 검토용 피드백 문구 공유본

Date: 2026-05-18
Scope: 대표님 공유용 피드백 문구 검토본
Status: review-only, app code not changed

## 1. 목적

현재 앱 결과 화면의 9개 평가 항목 문구를 평가표 기준에 맞춰 정교화하기 전, 대표님께 점수 방향과 표현 톤을 확인받기 위한 공유본입니다.

이 문서는 앱 반영본이 아닙니다. 점수 계산, score mapper, graph threshold, timeline mapping, API, 서버 기준은 변경하지 않았습니다.

## 2. 현재 앱 표시 항목

|---|---|---|---|

| 활성 | `vocal_fold_contact` | 성대 접촉 강도 | 문구 초안 검토 필요 |

## 3. 먼저 확인이 필요한 핵심 질문

1. `breathiness`는 `0~1 = 숨소리 과다`, `4~5 = 숨소리 적음/압축 경향`으로 보는 것이 맞습니까?
2. `forward_resonance`는 낮은 점수가 너무 앞쪽, 높은 점수가 뒤쪽/어두움으로 읽히는 것이 맞습니까?
3. `nasal_oral_ratio`는 단일 high/low 축이 아니라 `비강 과다`와 `구강 과다`의 양방향 불균형으로 봐야 합니까?
4. `larynx_tongue_root`의 사용자 표시명을 현재처럼 `공명 개방감`으로 유지해도 됩니까, 아니면 `후두/혀뿌리 위치`에 가깝게 바꾸는 편이 맞습니까?
5. 이번 앱 문구 정교화는 기준표 ver.3을 우선 기준으로 사용해도 됩니까?

## 4. 활성 4항목 문구 초안

아래 문구는 검토용 초안입니다. 대표님 확인 전 앱에 반영하지 않습니다.

| 항목 | 미달 초안 | 적절 초안 | 과함 초안 | 확인 질문 |
|---|---|---|---|---|
| 호흡 소리 식별 | 숨소리가 소리에 많이 섞여 발성의 중심이 흐려지는 경향 | 필요한 호흡감과 발성의 밀도가 자연스럽게 섞인 상태 | 숨소리가 거의 들리지 않고 소리가 조밀하거나 눌린 듯한 경향 | `0~1`을 숨소리 과다, `4~5`를 압축/숨소리 적음으로 봐도 되는지 확인 필요 |
| 성대 접촉 강도 | 성대 접촉이 약해 소리가 가볍거나 흔들리는 경향 | 접촉이 안정적이고 소리의 선명도가 유지되는 상태 | 접촉이 강해 소리가 눌리거나 거칠게 느껴지는 경향 | 낮음/높음을 `약함/강함`으로 표현하되, 높은 점수에는 `눌림/거침`을 함께 써도 되는지 확인 필요 |
| 연구개 위치 | 입 안쪽 공간이 낮거나 좁아져 소리가 답답하게 느껴지는 경향 | 입 안쪽 공간과 연구개 위치가 안정적으로 유지되는 상태 | 입 안쪽 공간에 긴장이 더해져 소리가 경직되는 경향 | 미달/과함을 `공간 좁음`과 `과도한 긴장`으로 표현해도 되는지 확인 필요 |
| 혀/구강 공간 경직도 | 혀와 구강 공간의 지지가 부족해 발음이 흐리거나 윤곽이 약해지는 경향 | 긴장도가 자연스럽고 발음의 선명도가 유지되는 상태 | 혀나 입 안쪽에 힘이 들어가 소리가 뭉개지거나 경직되는 경향 | 미달을 `낮은 지지/흐린 발음`, 과함을 `경직/뭉개짐`으로 분리해도 되는지 확인 필요 |

문구 톤 기준:
- `진단`, `장애`, `치료`, `반드시`처럼 임상적이거나 단정적인 표현은 사용하지 않습니다.
- 앱에서는 `경향`, `확인해 볼 수 있습니다`, `도움이 될 수 있습니다`처럼 발성 교육 보조 수준으로 낮춰 표현합니다.

## 5. 비활성 5항목 표시명/설명 확인 질문

현재 비활성 항목은 정식 점수 피드백보다 참고용 설명으로 유지하는 것이 안전합니다.

| 항목 | 참고용 설명 후보 | 확인 질문 | 현재 판단 |
|---|---|---|---|
| 비강/구강 공명 비율 | 비강과 구강 쪽 울림이 어느 한쪽으로 치우치는지 참고하는 항목 | 한 축의 높고 낮음인지, 비강 과다/구강 과다 양방향 불균형인지 확인 필요 | 확인 전 앱 반영 보류 |
| 흉성/두성 경향 | 흉성 또는 두성 쪽으로 소리가 치우치는 경향과 전환 느낌을 참고하는 항목 | 낮은 점수는 두성 우세/가벼움, 높은 점수는 흉성 우세/무거움으로 설명해도 되는지 확인 필요 | 참고용 설명은 비교적 안전 |
| 전방 공명 정도 | 소리 위치감이 너무 앞쪽으로 날카롭거나 반대로 뒤로 물러나는지 참고하는 항목 | 낮은 점수가 너무 앞쪽, 높은 점수가 뒤쪽/어두움인지 확인 필요 | 확인 전 앱 반영 보류 |
| 상압/하압 비율 | 발성 압력이 위쪽 또는 아래쪽으로 치우치는 경향을 참고하는 항목 | `상압/하압` 용어를 그대로 쓸지, `가벼움/눌림/밀어붙임` 중심으로 풀어 쓸지 확인 필요 | 참고용 설명은 가능하나 용어 톤 확인 필요 |
| 후두/혀뿌리 위치 또는 공명 개방감 | 후두와 혀뿌리 주변의 위치감, 목 안쪽 공간의 열림을 참고하는 항목 | 앱 표시명을 `공명 개방감`으로 유지할지 `후두/혀뿌리 위치`로 좁힐지 확인 필요 | 표시명 확인 전 보류 |

## 6. 앱 반영 전 결정 필요 사항

- `breathiness` 점수 방향을 확정해야 합니다.
- `forward_resonance` 점수 방향과 현재 앱 표시명의 충돌 가능성을 확인해야 합니다.
- `nasal_oral_ratio`를 단일 축으로 표현할지 양방향 불균형으로 표현할지 결정해야 합니다.
- `larynx_tongue_root` 표시명을 유지할지 변경할지 결정해야 합니다.
- 기준표 ver.3을 우선 사용할지 확인해야 합니다.
- 대표님이 부담스럽거나 단정적으로 느끼는 표현을 표시해 주시면 앱 반영 전 완화합니다.

## 7. 대표님께 보낼 메시지 초안

대표님, 현재 앱 결과 화면의 피드백 문구를 평가표 기준에 맞춰 조금 더 정교화하려고 합니다.

지금 앱에는 9개 항목이 있고, 그중 4개 항목은 결과 화면에서 활성 피드백으로 사용 중이며 5개 항목은 아직 참고용 또는 비활성 상태입니다. 앱에 바로 반영하기 전에 점수 방향과 표현이 평가 의도에 맞는지 먼저 확인받고 싶습니다.

특히 아래 네 가지는 확인이 필요합니다.

1. 호흡 소리 식별은 `0~1 = 숨소리 과다`, `4~5 = 숨소리 적음/압축 경향`으로 보는 것이 맞는지
2. 전방 공명 정도는 낮은 점수가 너무 앞쪽, 높은 점수가 뒤쪽/어두움으로 읽히는 것이 맞는지
3. 비강/구강 공명 비율은 한 축이 아니라 비강 과다/구강 과다의 양방향 불균형으로 봐야 하는지
4. 후두/혀뿌리 위치 항목은 앱 표시명을 현재 `공명 개방감`으로 유지해도 되는지

아래 초안은 앱 반영 전 검토용입니다. 표현이 너무 단정적이거나 학생에게 부담스럽게 들리는 부분이 있으면 알려주시면, 답변 기준으로 앱 문구에 반영하겠습니다.
